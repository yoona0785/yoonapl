# 1. 业务背景

## 1.1 需求描述

为敏宝家庭提供视频课程陪伴服务，支持免费学习与整课付费购买。运营在后台维护课程、分类、章节及试看内容，用户在小程序选课、试看、使用优惠券或积分抵扣、提交订单并支付，支付成功后解锁整门课程，后续从“我的课程”继续观看。

付费课程复用平台已有供应商、支付配置、支付分账、积分权益和订单管理体系，新增“课程”分账场景、“课程支付”交易类型及独立课程订单入口。

**文档基准**：2026-11-02 最终原型 `付费课程.html`。本文为整合后的有效规则，覆盖此前迭代说明中的旧口径。页面交互已通过原型逻辑检查；不代表真实支付、真实分账、服务端视频鉴权或正式积分系统已接入。

## 1.3 目标结果

1. 跑通“课程专栏 → 课程详情 → 免费试看 → 确认订单 → 订单支付 → 支付成功 → 解锁课程 → 我的课程 → 继续观看”。
2. 免费课程无需下单，点击观看后加入我的课程。
3. 前后台课程订单统一为“待付款、已完成、已关闭”，订单与学习进度分别管理。
4. 运营能够查看付费人数、现金实付金额、成交明细和课程分账记录。
5. 课程分类、上下架、支付渠道、积分适用范围及规则时间在前后台保持一致。

# 2. 关键业务规则

## 4.1 唯一性 / 并发性

1. 课程、课程分类、收款配置、支付配置、订单、操作日志均以独立ID识别；编辑按ID回填，不以名称作为记录标识。
2. 课程分类名称去除首尾空格后不可重复，课程名称不要求全平台唯一。
3. 同一供应商编码与分账场景的组合只能存在一条收款配置。
4. 同一用户已获得某付费课程权益后，不再重复购课，购买入口转为观看。
5. 存在同课程有效待付款订单时，重新点击购买优先进入该订单支付页；重复点击提交不重复建单。
6. 支付成功处理幂等：同一订单不得重复扣积分、核销优惠券、发放课程权益或生成完成记录。
7. 待付款订单占用已选优惠券与积分；其他订单仅可使用未占用余额。取消微信支付、支付失败不释放占用；主动取消订单或超时关闭释放占用，成功支付转为实际使用。
8. 原型已处理同毫秒新建记录ID冲突；生产环境需以服务端唯一约束、事务与支付单幂等保证并发一致性，不以页面检查替代。

## 4.2 字段定义

### 4.2.1 课程管理列表与统计

**搜索字段**：课程名称模糊搜索；课程类型、后台分类、状态精确筛选。更多搜索含课程ID、创建日期、课程分类。多条件为AND；重置清空条件。

**状态搜索**仅“全部、上架、下架”，不使用状态Tab，也不单列草稿。

**列表字段**：勾选、课程封面/名称/ID、供应商编码、课程类型、后台分类、课程分类、章节数、售价、付费人数、状态开关、创建人及时间、更新人及时间、操作。

1. 状态列仅显示开关，不显示“上架/下架”文字；开启为上架、关闭为下架。
2. 上架课程操作：编辑、下架、复制、日志；下架课程操作：编辑、上架、复制、删除、日志。编辑和状态操作行内展示，其余收入更多菜单。
3. 支持当前页全选、半选、选中数量及批量上下架、删除。上架课程不可删除；下架课程可软删除。
4. 默认每页15条，可选30、50条；按创建时间倒序排列。
5. 列表不提供导出；新增旁提供“课程分类”配置入口。
6. 顶部数据卡展示累计付费人数和付费金额，附更新时间、刷新与“查看数据”入口，不随课程列表搜索条件变化。
7. 付费人数可点击，进入数据统计明细并预填当前课程ID；“查看数据”默认查全部课程。

**统计明细**：课程信息、用户信息、付费记录、付费金额四组字段；支持用户ID/手机号、昵称、课程、付款日期筛选，默认20条/页，可选30、50条。订单编号跳转对应后台课程订单详情。

### 4.2.2 课程新增 / 编辑 / 详情

基础信息字段顺序如下：

| 字段 | 是否必填 | 默认与限制 | 展示与联动 |
| --- | --- | --- | --- |
| 课程名称 | 是 | 新增为空，最多50字 | 列表、详情、订单及前台展示 |
| 后台分类 | 否 | 选择现有商品中心分类管理中的分类 | 内部管理分类，原型使用共享模拟分类库，不展示来源说明 |
| 课程分类 | 否 | 单选已启用课程分类，默认空 | 用于小程序内容分类，与后台分类独立 |
| 讲师姓名 | 否 | 默认空，最多20字 | 未填写时前台不显示讲师占位 |
| 课程封面 | 上架必填 | JPG/PNG，最大5MB，建议16:9 | 上传后预览；内置示例封面按已有封面处理 |
| 课程简介 | 否 | 富文本，默认空 | 位于课程详情字段之前；填写后显示在前台课程标题下，未填写隐藏，无额外默认宣传文案 |
| 课程详情 | 上架必填 | 富文本，默认空 | 小程序课程介绍展示 |

富文本框使用白底、浅灰细边框、紧凑图标工具栏和较宽编辑区域。支持正文/标题/引用、加粗、斜体、下划线、列表、对齐、清除格式、图片、撤销重做及全屏编辑。图片支持PNG/JPG/WebP，原型单张最大2MB；粘贴正文按纯文本处理，保存清理不支持的标签与属性。富文本总长度、总图片数量与总内容大小上限待确认，不沿用旧版500字简介限制。

价格信息字段：

| 字段 | 是否必填 | 默认与限制 | 展示与联动 |
| --- | --- | --- | --- |
| 课程类型 | 是 | 新增默认付费；免费/付费 | 已产生已支付订单后禁止变更类型 |
| 供应商编码 | 付费时是 | 从既有供应商中单选 | 仅付费课程显示，移入价格信息；免费课保存不关联供应商 |
| 课程售价 | 付费上架必填 | 0.01—99999.99元，最多2位小数 | 免费课程价格为0 |
| 课程划线价 | 否 | 仅付费显示，非负金额，最多2位小数 | 前台未购课程列表/详情展示删除线；已购详情隐藏 |
| 虚拟销量 | 否 | 默认空，非负整数 | 仅作为前台销量展示参数，不进入后台付费统计 |

不再配置“观看有效期”。课程简介、虚拟销量下不显示解释说明。划线价是否必须大于售价目前未限制，待确认。

章节配置：

1. “添加章节”位于表格上方；表格含排序、章节名称、视频、免费试看及操作。免费课程不展示试看勾选列。
2. 上架至少1个章节；章节名称必填、最多50字；视频必填且时长大于0。支持MP4/WebM、本地上传及原型演示视频。
3. 章节可上下移动排序、删除；删除需确认。课程已售后不可删除原有章节，可追加章节，修改标题和试看标记。
4. 付费课程至少1个免费试看章节，试看为整章免费，不配置试看秒数；移除界面说明不取消校验。
5. 视频大小、编码、清晰度与单课章节数上限待确认；原型没有实现生产转码与上传进度服务。

发布设置：

1. 单选“立即上架、保存草稿”，默认保存草稿；不展示下方说明。
2. “保存草稿”为保存操作，最终列表状态记为下架，不新增第三种课程状态。
3. 保存草稿需校验课程名称及价格信息中已填字段格式；付费供应商仍必填。允许暂不补齐封面、详情、章节及售价。
4. 立即上架校验全部上架必填与试看规则。下架课程进入编辑默认按保存草稿展示，保存后仍下架，除非选择立即上架。
5. 未保存的主表单返回、关闭或切换页面时需确认；校验失败保留输入并定位字段错误；保存成功回到列表。
6. 查看详情只读；编辑进入独立页签。分区锚点在配置区域右侧，随页面滚动保持可用，点击定位分区顶部。

### 4.2.3 课程分类配置

1. 入口为“课程管理－课程分类”，不恢复商品中心菜单。
2. 分类名称必填、20字以内、去除首尾空格后唯一；排序非负整数；状态默认启用。
3. 支持新增、编辑、上移、下移、启停；按排序升序展示，排序相同按ID稳定排列。
4. 停用需确认，仅隐藏前台分类入口并禁止新课程选择，不下架关联课程，不清除原关联，不影响已有权益。
5. 列表展示排序、名称、关联未删除课程数、状态开关、更新时间、操作。本期无分类删除入口。

### 4.2.4 后台课程订单

**搜索**：关键词匹配订单号、课程名称/ID、用户ID、昵称、手机号；时间可选创建/付款时间及起止时间，快捷选今天、昨天、近7天、近30天；其他条件含用户ID/昵称、课程名称/ID。去掉供应商编码、支付方式、仓库、物流、售后搜索。状态Tab为全部、待付款、已完成、已关闭。

**列表**：按订单分组头展示订单号、创建时间、课程订单标签、后台备注；明细含课程封面/名称/ID、单价、数量1、优惠、应付金额、用户信息、订单状态及详情入口。课程列不展示讲师、章节。

优惠列仅在实际使用时显示：

- 优惠券单行：“券ID / 券名称 / 优惠 ¥10.00”。
- 积分：“抵扣积分：¥75.00”，不展示消耗积分数量。
- 未使用优惠券或积分时不展示对应记录或“未使用”提示。

列表只有一个“导出”入口，无新增订单、商品导出。默认15条/页，可选30、50条，创建时间倒序。

**详情**：

1. 状态进程展示创建、付款、课程解锁、订单完成；关闭订单展示创建与关闭。完成指交易完成，不代表课程看完。
2. 订单信息含主单编号、订单编号、订单类型、创建/付款时间、支付方式、支付单号、交易流水号、支付状态、已使用优惠券、优惠券优惠金额、积分抵扣、使用积分、买家备注、后台备注。已使用优惠券合并名称与ID，多张换行；去掉供应商编码。不再保留独立“优惠券使用记录”区域。
3. 用户信息含用户ID、昵称、手机号、订单邀请人、订单邀请渠道、unionid、openId、external_userid、系统标签；不展示订单来源；无数据展示“—”。
4. 课程信息含封面/名称/ID、分账信息查看、订单状态、单价、数量1、原总价、课程优惠、实付总价；无讲师、章节、供应商编码。
5. 课程优惠逐行展示：“积分抵扣：¥75.00”“优惠券抵扣：（优惠券名称/100713）¥75.00”，无优惠显示“—”。
6. 底部汇总应付/实付金额，并列出订单日志。未付款或关闭订单实付为0，原应付金额保留。
7. 分账信息弹窗含账户名称、分账账号、分账金额、分账状态；未支付无分账记录，已支付但无配置时显示无记录。

### 4.2.5 支付分账与支付配置

**支付分账**：按供应商名称、编码、分账场景筛选；列含ID、供应商名称/编码、场景、连连/微信分账方与商户号、创建/更新时间、操作。支持新建、编辑、删除、操作记录，默认20条/页，可选50条。

**分账设置**：

1. 保留原有大贸、保税、直邮、积分、赠品场景，新增“课程”。
2. 可选分账方：供应商货款、售后赔付金、跨境综合税、平台佣金、平台差价、技术服务费、平台服务费（支付手续费）。勾选后配置该方公式，不显示“选择需要参与当前场景分账的分账方”说明。

4. 示例供应商80%、平台20%只是模拟初值，不视为正式业务比例。

**新建/编辑收款**：供应商编码必填并自动带出名称；分账场景单选且单行排列，选择课程读取已保存的分账方、公式；按分账方填写连连、微信收款商户号。至少完整配置一个渠道，一个渠道只要填写就必须补齐全部分账方。商户号原型校验1—32位字母、数字或下划线，生产格式以接入渠道为准。移除渠道成组填写的说明文案，但保留校验。

### 4.2.6 积分消耗规则

列表保留下单抵扣比例、通用抵扣规则、特殊人群规则，增加“生效时间”列。移除状态与刷新入口，不增加独立生效设置行；立即生效显示文案，定时显示起止时间到秒。

1. 抵扣比例为正整数R，表示R积分=1元；平台承担比例为0—100%，供应商比例自动补足至100%。
2. 通用与特殊规则分别有启停、订单金额门槛、抵扣上限、参与商品、付费课程。门槛可不限或满指定金额；上限可不限、指定金额或指定百分比，限制值大于0，百分比不超过100%。
3. 参与商品为全部、指定类型、指定商品；可填写不参与商品。商品ID以数字校验，多个逗号分隔；指定类型至少1个，指定商品至少1个有效格式ID。原型未查询真实商品库。
4. 付费课程单选参与/不参与，默认不参与；商品范围不自动包含课程。参与后选全部付费课程或指定付费课程；原型首次指定范围默认空，可切换全部。
5. 全部付费课程动态包含新增课程。指定范围只在表单显示已选数量及选择/修改入口，不铺开长ID文本。
6. 课程选择弹窗仅可选择未删除的付费课，支持名称/ID、后台分类、上下架搜索，分页10/20/50条、跨页保留、当前页全选和半选、查看已选、移除、清空。
7. 批量粘贴支持逗号、中文逗号、空白或换行分隔，自动去重，分别提示重复、无效、免费、已删除课程；合法部分可加入。失效已选项可移除，不能被全选加入。
8. 弹窗确定回写外层草稿，取消不修改原选择；外层保存才持久化。指定范围至少1门有效付费课；不参与或关闭规则时，隐藏选择不触发校验。
9. 特殊规则另需选择参与用户群，原型为敏宝家庭会员、新用户家庭、高活跃家庭。通用与特殊范围独立保存。
10. 单项编辑仅展示本项及本项生效时间，保存不影响其他项；编辑全部底部仅一组时间，统一应用三项。
11. 字段标签不换行、统一对齐，不展示已移除的北京时间说明。

### 4.2.7 积分发放规则

1. 列表字段为规则名称、规则详情、生效时间、更新记录、操作；规则详情不重复展示生效时间和生效状态。

6. 发放规则本期只完成配置存储；不据此宣称购课后已真实增加奖励积分。

## 4.3 计算规则

### 4.3.1 前端销量与后台统计

1. 付费课程前端展示销量 = max（该课程已支付订单笔数，虚拟销量）。免费课不显示购买人数。
2. 后台累计付费人数 = 全部已支付课程订单按用户ID去重；同一用户买多门课累计只计1人。单课程付费人数按该课程与用户ID去重。
3. 付费金额 = 已支付订单现金实付合计；不含积分抵扣和优惠券优惠，不计待付款、失败、关闭订单。
4. 0元全额抵扣成功订单计入成交及付费人数，现金付费金额贡献为0。名称仍沿用“付费人数”。
5. 原型后台示例成交会计入统计和展示销量，但不向当前体验账号发放权益；正式环境不生成示例成交。

### 4.3.2 优惠券与积分

1. 本期先减优惠券再算积分，前台最多选1张可用券；券优惠不得超过课程原价。
2. 券后金额P = 课程原价 − 优惠券优惠。积分门槛按P判断；满足有效特殊人群规则时优先使用特殊规则，否则使用有效通用规则，两者不叠加。
3. 抵扣比例、对应人群规则须处于有效时间内；关闭、不参与或课程不在范围内均不可抵扣。
4. 可抵上限C：不限时取P；按金额时取min(P,金额上限)；按比例时取min(P,P×比例)。
5. 最大抵扣元数U = min（floor(C)，floor(可用积分/R)）；使用积分时抵扣U元、消耗U×R积分，不使用为0。
6. 可用积分 = 积分余额 − 其他有效待付款订单已占用积分；支付当前订单时排除本单自身占用，防止二次扣减计算。
7. 订单应付金额 = 课程原价 − 优惠券优惠 − 积分抵扣，不得小于0，金额保留2位小数。
8. 示例：原价99元，优惠券10元，券后89元，积分上限20%，R=10。上限17.80元向下取整为17元，使用170积分，现金实付72元。
9. 0元订单需用户确认后完成，不调用有现金金额的支付；记录支付方式为“优惠抵扣支付”。
10. 不可用券展示门槛未满足/已使用等原因；提交时重新校验，已不可用不静默改成无券。

### 4.3.3 分账

1. 以订单现金实付金额作为“订单实付金额”公式变量；先乘除后加减，固定值非负，结果按分取两位小数。
2. 支付成功时按课程供应商、课程场景和支付渠道生成模拟分账快照；后续修改公式、商户号或课程不回算历史快照。
3. 当前演示显示“未分账”，并不发起资金划转。0元订单没有现金待分账。
4. 原型试算会提示分账合计与实付不一致，但尚未实现正式的总额强校验、尾差归属、通道手续费及积分/券承担方结算。上述规则待确认，不能直接作为生产结算结果。

## 4.4 关键联动逻辑

1. 课程保存、分类改名/排序/启停、上下架在管理页及小程序共享数据。新增课程按独立分类ID保存，不依赖分类名称匹配。
2. 下架后不再向无权益用户开放购买；已有权益可继续学习。删除为软删除，管理与公开列表隐藏，历史订单、统计及已有观看权益保留。
3. 已售课程类型和原有章节删除受限，避免已购权益被破坏；复制生成独立ID并默认下架。
4. 每个页面独立页签，切换与刷新恢复对应课程/订单上下文；不可因全局当前课程变化而串课。
5. 确认订单后点击提交才建单，并保存课程、价格、供应商、优惠、积分、买家备注、用户等交易快照。
6. 已启用且交易类型为课程支付的配置才进入课程支付页；支付确认保存通道配置ID、名称、渠道和主商户号快照，不保存密钥到订单。
7. 已选通道停用不暗中替换为其他通道，应提示暂不可支付，并由用户重新选择可用方式。
8. 成功支付将订单置已完成、写入付款/解锁/完成时间、发放课程权益并扣减占用积分；后台订单与统计同步。
9. 支付失败、取消微信支付、普通返回保持待付款，不解锁、不扣除实际积分；明确取消订单或超时才已关闭并释放优惠占用。
10. 已关闭重新购买生成新订单，旧单保留。免费开始学习不生成订单。
11. 观看保存最近章节、秒数、完成标记；刷新后恢复，下一节按章节顺序播放，最后一节返回课程。
12. 课程选择器、规则单项编辑、编辑全部分层保存：弹窗确定只更新外层草稿，规则保存才持久化。
13. 单项积分时间只修改本项；编辑全部共用时间覆盖消耗三项，或覆盖发放当前勾选任务，未勾选任务配置保留。

## 4.5 异常处理规则

1. 必填缺失、价格精度不符、虚拟销量负数/小数、无效分类、无章节视频、无付费试看章，阻止上架并显示对应错误。
2. 付费供应商无效、重复供应商＋场景、渠道商户号不完整、公式不完整/除零/负数，阻止对应配置保存。
3. 没有启用课程支付配置、已选配置停用、余额不足、券被其他有效订单占用或使用、订单过期，阻止支付；不得发放权益或产生第二次扣减。
4. 播放失败保留位置，提示重新上传/重试；无可播放章节不得加入学习，未购访问锁定章提示购买。
5. 前后台课程已下架/删除后，无权益用户不可通过旧入口学习免费课或发起购买；已有权益不受该状态影响。
6. 定时未填完整、失效不晚于生效、失效不晚于当前时间均阻止保存。开始时间允许早于当前时间，只要结束仍在未来。
7. 取消或关闭弹窗不保存；主表单未保存离开需确认。删除、下架、停用及取消订单使用明确确认交互。
8. 原型数据写入本地空间失败时提示空间不足；正式接口错误、请求重试和幂等错误需以服务端返回为准。

## 4.6 权限规则（按需）

1. 后台课程配置、支付、分账、积分和导出沿用平台现有对应模块权限；原型未实现角色鉴权及无权限拦截。
2. 前台课程订单仅当前登录用户可查；不得展示后台其他用户示例订单。生产接口必须验证订单归属及课程权益，不能只靠隐藏按钮。
3. 未购付费课只能访问试看章节，已购后解锁全部；免费课按公开状态访问，已有学习权益保留。
4. 用户身份使用原平台账号体系。原型只使用模拟用户及脱敏手机号，不要求新增实名认证流程。
5. 具体角色、导出权限及敏感用户标识可见范围待按现有权限模型确认。

## 4.7 时效与有效期（按需）

1. 订单支付窗口为提交后30分钟，显示剩余分秒；超时自动关闭并记录原因，不从每次重试重新起算。
2. 原型在支付页倒计时和订单列表/详情查询时检查超时；生产环境需服务端定时关单，不能依赖用户打开页面。
3. 积分规则支持立即生效或定时生效，定时起止精确到秒，以北京时间解释；有效区间为开始时间≤当前时间＜失效时间。
4. 编辑全部仅一组生效时间；单项可独立设置，列表按各记录保存的实际时间展示。
5. 当前原型定时保存直接替换该项配置，未维护“旧规则持续有效至新规则生效”的版本切换；是否需要旧规则续用及多版本排期待确认。
6. 不提供课程观看有效期字段，也不展示长期有效文案；目前权益未设置自动到期。未来课程停服或内容撤下处理另行确认。

## 4.8 数据来源（按需）

1. 课程与章节由课程管理维护；后台分类来自现有商品分类管理，课程分类来自本次独立课程分类库。
2. 供应商编码来自现有供应商库，名称自动带出；不允许自造编码绕过选择。
3. 支付、分账、积分页面复用现有业务模型，新增课程场景；用户标识来自现有账号系统，无来源不虚构。
4. 历史课程/价格/优惠/分账信息取订单快照，课程当前状态和分类可取最新配置；快照与实时字段不能混淆。
5. 原型课程订单、权益、进度、配置、演示积分余额、页面上下文保存在当前浏览器；不跨账号、设备或浏览器同步。
6. 原型初始积分余额1000、两张课程优惠券、示例课程、示例历史订单、演示支付配置均仅供验证，不是正式业务默认值。无课程支付配置时一次性生成DEMO商户号演示配置，不表示真实收款能力。
7. 已上传本地视频使用临时链接，刷新后需重新选择；课程元数据和图片持久化不代表视频文件已上传到正式存储。

## 4.9 通知机制（按需）

1. 原型提供保存、校验、上下架、选课、提交、支付、取消与超时的页面反馈。
2. 不发送短信、订阅消息、企微通知、邮件，不自动向外部人员发送消息。
3. 正式支付结果以服务端验签回调为准；回调成功与前台返回不一致时，应查询支付单并重试解锁，不要求重复付款。该回调补偿尚未接入原型。

## 4.10 上限与极限（按需）

1. 一门课一次整课购买、数量固定1；课程分类为一级、单选。
2. 名称、金额、图片、备注、说明限制按4.2执行；ID批量选择未限定总数量，数百条采用分页及ID集合，不在主表单铺开。
3. 课程选择弹窗全选仅当前页可选项；已删除、免费或无效项不可批量带入，跨页保留选择。
4. 原型虚拟销量、分类排序以可安全表示的非负整数校验；生产数据库上限、批量ID请求上限、导出最大记录数、视频大小及章节上限待确认。
5. 支付通道启用唯一性当前未限制同一交易类型多条配置，允许用户选择多个启用渠道；营销账户对应真实支付能力尚未接入。

## 5.3 空态

1. 后台列表无匹配显示暂无数据，不保留不存在记录的操作。
2. 小程序无课程/无匹配提示尝试其他关键词或分类。
3. 我的课程首次为空提供去看看课程；仅筛选无匹配时提供查看全部课程，不误导重复购买。
4. 课程订单按各状态无记录时显示对应空态和去看看课程。
5. 章节未添加、已选课程为空、操作日志为空、分账为空分别展示明确空态；无分账不能伪造成功记录。
6. 未填简介、讲师、未使用优惠不显示多余占位文案；用户系统字段无数据按“—”处理。

## 5.4 异常态 / 失败态

1. 支付失败：不解锁、不实际扣积分，保留待付款，可在原有效期继续支付。
2. 取消微信支付：提示取消本次支付，订单仍待付款；不误记用户取消订单。
3. 主动取消或超时：已关闭，实际支付金额0，记录关闭时间/原因并释放优惠占用。
4. 支付成功但正式解锁失败：支付事实保留，走权益补偿，属于生产接入要求；原型仅同步模拟成功。
5. 加载/提交状态须防重复交互；原型本地操作没有真实网络加载，接口耗时、超时与断网展示需正式接入时补齐。
6. 课程后续调价不改历史实付；支付成功后重放同回调不再次扣减。

## 5.5 权限态 / 不可操作态

1. 已售课程类型不可改，原有章节删除禁用。
2. 上架课程无删除入口；下架软删除后原已购课程仍可观看。
3. 未购非试看章节显示锁定，点击提示购买；下架且无权益不可购买或学习。
4. 已使用/占用券、余额不足、规则不适用时不可选择相应抵扣。
5. 已关闭订单不可继续支付，已完成不可取消；课程下架/删除时关闭订单重新购买入口应提示暂不可购买。
6. 已失效分类不供新选，但保留现有归属；无权限正式接口拒绝操作。

## 5.6 状态-操作矩阵（按需）

| 对象与状态 | 可执行操作 | 备注 |
| --- | --- | --- |
| 课程上架 | 编辑、下架、复制、日志 | 下架确认，复制默认下架 |
| 课程下架 | 编辑、上架、复制、删除、日志 | 上架完整校验；删除保留历史权益 |
| 未购付费课程 | 查看介绍/目录、试看、购买 | 不可播锁定章节 |
| 已购课程 | 开始/继续观看、查看订单 | 不显示当前售价 |
| 免费上架课程 | 免费观看 | 开始后加入我的课程，不生成订单 |
| 待付款订单 | 查看、继续支付、取消订单 | 有效30分钟 |
| 已完成订单 | 查看、观看课程 | 不代表已学完 |
| 已关闭订单 | 查看、重新购买 | 重购生成新单，不复活旧单 |
| 启用分类 | 编辑、排序、停用 | 停用不影响课程权益 |
| 停用分类 | 编辑、排序、启用 | 前端入口隐藏 |
| 规则单项编辑 | 本项配置及生效时间 | 不改其他规则 |
| 规则编辑全部 | 全部配置及一组共用时间 | 消耗三项/发放勾选任务统一应用 |

## 5.7 状态流转（按需）

1. 确认订单未提交 → 返回：无订单。
2. 提交成功 → 待付款：保存快照，占用优惠和积分。
3. 待付款 → 返回/失败/取消微信支付 → 待付款：保留原单及截止时间。
4. 待付款 → 支付成功 → 已完成：核销优惠、扣积分、解锁、记录实付及分账快照。
5. 待付款 → 主动取消/超时 → 已关闭：释放占用，不发放权益。
6. 已关闭 → 重新购买：创建新待付款订单，旧单不变。
7. 保存草稿 → 下架；下架 → 校验通过上架；上架 → 确认下架；下架 → 软删除。
8. 免费开始学习 → 已获学习权益；播放 → 保存秒数/章节；章节结束 → 标记已学完。

2. 支付配置新建、编辑、启停、删除；分账设置保存及收款配置新增/编辑/删除记录对应日志，不写入密钥明文。

## 6.3 ID 规则

1. 保留平台已有课程、供应商、用户、券及分类ID含义，跨页面传递记录ID，不以列表行号定位。

3. 支付回调以支付单和订单唯一关联；重新购买生成新订单ID，不复用关闭单。

## 6.4 通知

本期只提供站内页面反馈与状态同步，不扩展短信、企微或订阅通知。支付失败与关闭原因应在前台可见。

## 6.5 端能力限制

1. PC沿用参考后台布局、组件密度及主色；小程序按375×812手机画布与既有紫色体系展示。原型单文件，无外部前端库依赖。

5. 正式接入需补充支付验签、服务端鉴权、视频转码/存储/防盗链、优惠与积分事务、定时关单、权益补偿及分账对账。
