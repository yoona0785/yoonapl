
# 1. 业务背景

## 1.1 需求描述

1. 运营人员配置拼团活动的商品、价格、成团条件、参与人群、奖励和分享信息，通过商城装修投放到微信小程序。
2. 用户查看商品、发起或参与拼团，经奖励确认与提单后邀请好友成团，在我的订单查看交易信息及独立的拼团进度。
3. 后台查看拼团统计、用户参团记录和关联订单，并在订单管理中增加拼团状态展示与筛选。
4. 拼团为订单关联的营销属性，不新增“拼团订单”类型，不以拼团状态替代交易状态。

## 1.3 目标结果

1. 串联“活动配置—装修发布—商品详情—奖励确认—确认订单—拼团详情—我的订单—后台订单管理”。

## 1.4 本期范围

1. 营销中心：活动列表、新建/编辑、活动商品、推广、日志、拼团记录、关联用户与订单查看。
2. 商城装修：页面列表、装修编辑、页面配置、组件管理、拼团组件配置及预览。
3. 订单中心：订单管理列表、搜索、分页、导出、订单详情及拼团状态。
4. 微信小程序：装修页、商品详情、奖励弹层、确认订单、规则独立页、拼团详情、邀请分享、我的订单及订单详情。

# 2. 关键业务规则

## 4.1 唯一性 / 并发性

1. 同一活动的同一商品规格不能重复添加；选择器的已选、禁用或不可选项不得重复带入。
2. 开团与参团分别判断人群资格和次数，进入提单及提交时复查资格、活动和团状态。
3. 同用户重复参同一团、退款恢复额度。

## 4.2 字段定义

### 4.2.1 拼团活动列表

1. 页面路径：营销中心 → 拼团活动。
2. 活动数据：开团数、成团数、成交金额、更新时间、刷新、查看拼团记录。
3. 搜索：活动名称包含匹配；活动ID忽略大小写包含匹配；活动状态下拉“全部/待开始/进行中/已结束”；活动开始/结束日期范围。非空条件间为AND。
4. 时间条件按活动开始日期不早于查询开始、活动结束日期不晚于查询结束判断，即区间包含，不是区间相交。
5. 查询表：名称/ID、活动时间、开团数/成团数、创建时间、状态、操作；无匹配显示“暂无匹配活动”。
6. 点击开团数或成团数进入对应活动记录；当前原型均只带活动条件，成团数未额外预选“已成团”。
7. 新建/编辑保存更新数据并返回；结束、删除经二次确认，取消不改数据。

### 4.2.2 活动新建/编辑：基础信息

| 字段 | 控件/必填 | 默认及约束 |
| --- | --- | --- |
| 活动名称 | 单行文本，必填 | 最多50字，去首尾空格后不能为空 |
| 活动标签 | 单行文本，必填 | 最多10字，用于商品价格标签 |
| 活动时间 | 开始/结束日期时间，必填 | 新建空；结束晚于开始 |
| 活动规则说明 | 富文本，选填 | 默认空，最多4000字 |
| 活动总数量 | 非负数，选填 | 空/0表示未设限制 |
| 活动用户限购 | 非负数，选填 | 空/0不限，与商品用户限购共同约束 |
| 平台优惠承担比例 | 数值 | 新建0%，不得为负 |
| 供应商优惠承担比例 | 数值 | 新建100%，两项合计100% |
| 积分抵扣、优惠券叠加 | 复选 | 新建不勾选 |

1. 已配置规则：商品详情、拼团详情显示“拼团规则”；确认订单显示“点击查看 拼团规则”。点击进入独立规则页。
2. 未配置规则：上述入口全部隐藏，不填充固定默认规则。

### 4.2.3 活动新建/编辑：拼团规则

| 字段 | 默认及约束 |
| --- | --- |
| 成团人数 | 必填，新建空，页面标注2–100人；保存至少校验2人 |
| 成团时限 | 必填，默认24小时，大于0 |
| 开团次数 | 选填，空/0不限，按活动和当前用户统计 |
| 参团次数 | 选填，空/0不限，与开团次数独立 |
| 凑团 | 新建默认开启 |
| 自动成团 | 新建默认关闭，开启显示条件 |
| 距截止分钟数 | 条件必填，默认5分钟，大于0 |
| 自动成团人数阈值 | 条件必填，默认1人，大于0且小于成团人数 |
| 开团人员限制 | 不限制/指定用户群/指定标签/新客/指定用户，默认不限制 |
| 参团人员限制 | 同上，独立配置，默认不限制 |

1. 不限制和新客均隐藏“指定范围”。
2. 指定用户群/标签展示相应选择；指定用户填写用户ID，原型支持逗号、中文逗号或空白分隔。
3. 超次分别提示开团次数或参团次数达到上限；无资格分别提示不能开团或不能参与。

### 4.2.4 活动新建/编辑：奖励、商品、推广

1. 开团奖励、参团奖励分别配置，可同时勾选积分和优惠券；新建均不勾选。
2. 积分勾选后必填且大于0；控件初始值开团100、参团50，不勾选不生效；整数校验、上限及实际发放待确认。
3. 优惠券勾选后至少选择一张，仅可选手动发放类型；支持名称、ID、类型及日期搜索，全选仅作用于可选择项。
4. 已选券展示赠券数、名称、优惠信息、发券时间、优惠承担、有效期、发券量/领取数和删除；数量大于0且不超过剩余可发数。历史示例券兼容不作为正式业务豁免。
5. 至少配置一个商品规格，支持商品/规格选择、去重、删除、单项编辑及批量设置。
6. 商品表字段：拼团价、库存、商品活动数量、商品用户限购、排序值、售价、名称、属性、规格数量、操作。
7. 拼团价必填、大于0且低于规格售价；金额元、展示两位小数；活动数量及用户限购非负，空/0表示不限。
8. 批量只覆盖已填写字段；全部未填或没有商品时提示。独立活动商品页保存回写活动，取消不写入。
9. “仅组件展示”勾选后只有通过活动入口可享受拼团价。
10. 开启分享后标题及图片必填，标题最多50字，原型分享图片限制2MB；关闭隐藏配置。

### 4.2.5 拼团记录

1. 页面路径：活动列表 → 查看拼团记录，或活动行开团数/成团数。
2. 搜索：活动、活动状态、用户手机号、用户ID、用户昵称、拼团状态。手机号包含匹配，ID/昵称忽略大小写包含匹配，其余枚举精确匹配。
3. 条件间AND；用户可命中开团或参团成员，多个用户条件需由同一成员同时满足。
4. 表字段：活动名称/ID/状态、商品名称/ID、开团用户昵称/手机号/ID/注册时间、订单号/下单时间、参团人数、开团时间、成团时间、成团截止时间、拼团状态/进度。
5. 记录原始状态保持拼团中、已成团、未成团。
6. 参团人数点击查看成员；用户及订单点击进入关联详情，必须带对应记录ID。无结果显示空态；清空恢复全部。

### 4.2.6 拼团组件及小程序装修页

| 配置 | 默认/规则 |
| --- | --- |
| 组件备注 | 选填，50字 |
| 背景颜色 | #FFFFFF，可选择与重置 |
| 背景图 | 非必填，仅1张，上传显示缩略预览 |
| 样式 | 默认横向，可切纵向 |
| 横向 | 单行每行3个，超出横滑；或多行每行3个自动换行 |
| 纵向 | 单列每行1个；双列每行2个 |
| 活动导航、倒计时 | 默认显示，可隐藏 |
| 活动内容 | 支持多个活动、排序、移除及切换预览 |
| 可见范围 | 默认全部用户，可保存指定人群显示/隐藏值；实际人群配置与鉴权未闭环 |

1. 商品展示奶粉图、名称、最低拼团价、活动标签、规格售价划线价，不使用主图文字占位。
2. 有有效规格价集合时取最低值，无集合时用当前商品配置价。
3. 导航显示N人团及待开始/拼团中/已结束；未开始计至活动开始，其他计至活动结束，已结束归零。
4. 微信小程序装修页只显示拼团装修内容，读取首个已发布且含拼团组件的页面；按配置呈现背景、布局、活动顺序和倒计时。

### 4.2.7 商品详情、奖励、确认订单

1. 头图横幅展示拼团价、活动标签、原价划线价、距活动结束倒计时。
2. 凑团开启且有可参与团时，展示发起人、还差人数、剩余时间、参团按钮；无团隐藏整块。这里“未成团列表”指拼团中的团，不含已失败或满员团，按开团升序展示，最早开团未成团的展示在前。
3. 底部保留客服、购物车、收藏、单独购买、我要开团。
4. 开团/参团先校验资格、活动状态及目标团。当前操作有奖励先弹奖励层，无对应奖励直接提单。
5. 奖励层读取活动开团/参团配置，可展示两类奖励并标识本次适用部分；展示积分、券名、数量，按钮分别“确认开团”“确认参团”。
6. 提单展示拼团价。
7.  规则按活动配置显隐。

### 4.2.8 拼团详情与邀请好友

1. 开团成功：商品、还差人数、截止倒计时、发起人/空位、邀请好友、推荐商品；规则按配置显隐。
2. 拼团成功：成功图标、“恭喜你拼团成功！”、已满人数、成员、查看订单、逛逛首页、推荐商品及规则入口。
3. 失败但活动进行中：失败原因、再开一局，进入当前活动开团资格/奖励/提单链路。
4. 失败且活动结束，或有资格但活动结束：商品已结束覆盖、“该活动已结束！”、去商城逛逛，不可参团。
5. 无资格：弹“拼团提醒”，提示“您没有参与资格，无法参与该拼团”，我知道了关闭后按钮仍不可用。
6. 有资格但满员且活动进行中：显示“来晚一步，该团已成团”、满员头像和去开团，不能加入原团。
7. 本人已成功的团不因活动后来结束回退失败；访客进入结束活动不提供参团。
8. “拼团详情”入口含七场景：开团成功·邀请好友、拼团成功、失败·进行中、失败·已结束、无资格、有资格·已结束、有资格·人员已满。
9.  邀请海报含小程序logo、名称、商品主图、名称、“拼团价 ¥金额”、时间、小程序码。

### 4.2.9 小程序我的订单与订单详情

1. 订单类型仅普通订单、跨境订单、直邮订单，不增加拼团订单。
2. 拼团属性单独放底部营销条：待成团显示差人数/倒计时及邀请好友；成功显示已满人数；失败显示未达人数。非拼团订单不显示。
3. 商品/订单头进订单详情；营销条进对应拼团详情；邀请进入海报层。

### 4.2.12 后台订单管理与详情

1. 搜索增加拼团状态：全部、拼团成功、拼团失败、拼团中。
2. 订单头增加拼团状态；没有拼团属性不展示标签。
3.  详情增加拼团状态显示。
4.  订单导出增加拼团状态显示。

## 4.3 计算规则

1. 成团截止时间＝min（开团时间＋成团时限，活动结束时间）。记录、团详情、订单营销条统一，倒计时最低0，不出现NaN。
   1. 示例：10月22日15:00开团、时限24小时、活动10月23日10:00结束，截止为23日10:00。
   2. 若活动24日结束，截止为23日15:00。标准时区Asia/Shanghai，正式服务端时间与边界待接入。
2. 还差人数＝max（0，成团人数－成员数）；买多件不增加多人名额，原型一次参团增加1名成员。
3. 开团数＝团记录数量；成团数＝已成团团数；成交金额＝已成团记录amount之和。顶部统计不随活动列表筛选变化；行统计按活动ID。
4. 商品卡有规格价集合取最低拼团价，否则当前配置价。
5. 拼团优惠＝（售价－拼团价）×数量；小计＝拼团价×数量。
6. 活动限购、商品限购、商品活动数量中正值最小值，空/0不参与取小。
7. 自动成团条件为距截止进入配置分钟数且人数达到阈值。

## 4.4 关键联动逻辑

1. 发布装修联动拼团组件；活动导航切换更新当前组件商品与倒计时。
2. 开团与参团使用各自奖励、人群和次数。
3. 进入提单与提交均检查活动、资格、团状态和人数；关闭提醒不能绕过限制。
4. 原始团状态映射：已成团→拼团成功，未成团→拼团失败，拼团中→拼团中；小程序营销条把拼团中显示为待成团。

## 4.5 异常处理规则

1. 必填为空、时间不合法、人数/时限错误、承担比例错误、缺商品、价格错误、奖励缺值、规则超限阻止保存并提示，保留输入。
2. 空批量不覆盖、重复规格不添加；无商品不可保存活动。
3. 团不存在、失败、满员、超时或活动非进行中不可有效参团，按分支提示或引导逛商城/新开团。
4. 无资格弹窗关闭后仍禁用；未同意须知不可提单，提交时禁用按钮。

## 4.6 权限规则（按需）

1. 前台独立检查开团、参团人群资格和次数；组件可见范围不代替购买资格。

## 4.7 时效与有效期（按需）

1. 活动按开始/结束时间展示状态，结束不得新开或参团。
2. 团截止不因重进页面延长；已成功不因活动结束回退。

# 5. 状态与异常

## 5.1 业务状态

1. 活动：待开始、进行中、已结束。
2. 团记录：拼团中、已成团、未成团。
3. 订单拼团属性：拼团中、拼团成功、拼团失败；非拼团订单无属性。
4. 小程序订单营销条：待成团、拼团成功、拼团失败，与交易状态独立。

## 5.2 页面默认态

1. 活动默认列表全部，搜索空，统计全量；新建名称/标签/时间/人数空，时限24小时，凑团开，自动成团关、5分钟/1人，限制不限制，奖励/分享不选。
2. 拼团组件默认横向单行、导航/倒计时显示、白底、全部用户可见。
3. 提单数量1。

## 5.3 状态-操作矩阵（按需）

| 状态 | 可执行操作 | 备注 |
| --- | --- | --- |
| 活动待开始 | 编辑、复制、商品、推广、日志、删除 | 前台不可购买 |
| 活动进行中 | 编辑、复制、立即结束、商品、推广、日志 | 结束二次确认 |
| 活动已结束 | 复制、日志、删除 | 不再编辑/参与 |
| 本人拼团中 | 邀请好友、查看已配置规则 | 倒计时、剩余人数 |
| 本人拼团成功 | 查看订单、逛首页、查看规则 | 成功图标、满员头像 |
| 失败且活动进行中 | 再开一局 | 重新校验和提单 |
| 失败且活动结束 | 去商城逛逛 | 不再开团 |
| 访客无资格 | 我知道了、返回 | 关闭提醒不能绕过 |
| 有资格、活动结束 | 去商城逛逛 | 不进入提单 |
| 有资格、团满、活动进行中 | 去开团 | 不加入原团 |
| 有资格、有效拼团中 | 参团 | 有奖励先确认 |


## 5.7 状态流转（按需）

1. 活动待开始→到开始→进行中→到结束或立即结束→已结束。
2. 支付开团→拼团中；有效参团满人数→已成团；超时未满→未成团。
3. 开团/参团→若有对应奖励先确认→确认订单→须知同意→提交→支付→团详情；无奖励直接提单。

# 6. 衍生需求与默认授权项
