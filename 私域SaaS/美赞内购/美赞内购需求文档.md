# 1. 业务背景

## 1.1 需求描述

为了让具备医生身份的用户享受内购价，本期建立医生身份认证体系。用户在微信小程序提交认证资料，运营人员在私域运营平台审核；审核通过后，认证状态更新为“已认证”，系统同步维护医生资格和系统标签。运营人员可在标签和用户群中使用“身份认证”状态圈选人群，供后续内购活动价配置使用。

## 1.2 用户角色

- 普通用户：查看认证入口、提交资料、查看审核进度和结果、驳回后重新提交。
- 已认证医生：在个人信息页展示医生身份标识，可被医生标签和医生用户群命中。
- 运营人员：在用户管理列表和用户详情中查看认证状态、审核资料、通过或驳回申请、查看审核记录。

## 1.3 目标结果

- 建立“用户提交 → 运营审核 → 身份生效 → 标签/用户群圈选”的完整闭环。
- 医生身份只有一个可信来源：最新一次审核通过的认证记录。
- 小程序与运营后台共享同一认证状态和审核记录，状态变化后实时可见。
- 为后续内购活动按医生人群设置专属价格提供稳定的人群条件。

## 1.4 本期范围

- 用户管理列表：新增“身份认证”筛选与列表字段，状态为“未认证、待审核、已驳回、已认证”；待审核、已驳回用户提供“审核”操作。
- 用户详情：在用户资料中展示身份认证状态，支持通过详情弹窗查看提交认证信息与审核记录。
- 标签：用户特征新增“身份认证”；支持配置“待审核、已认证、已驳回、未认证”的自动标签；系统内置标签“医生”。
- 用户群：用户特征新增“身份认证”；支持配置“待审核、已认证、已驳回、未认证”的人群条件。
- 系统配置 / 业务配置：在“宝宝信息配置”下增加“身份认证配置”，支持开启或关闭身份认证入口，并配置填写跳转页面类型。
- 微信小程序个人中心主页：不展示医生认证入口；已认证用户仍展示医生身份标识。
- 微信小程序个人信息：新增“身份认证”字段与状态。
- 微信小程序医生认证：支持首次提交、待审核、审核通过、审核驳回和驳回后重新提交。

## 1.5 本期不做

- 不实现内购活动创建、商品选品和内购价配置页面。
- 不对接第三方医生资质数据库，不做自动验真。
- 不支持一个用户同时拥有多个医生认证主体。
- 不支持用户主动撤销已通过的医生身份；需线下联系运营处理。
- 不实现短信、订阅消息等站外通知，仅在小程序内展示审核结果。

# 2. 关键业务规则

## 2.1 认证状态定义

| 认证状态 | 用户端展示 | 用户可操作 | 运营可操作 |
| --- | --- | --- | --- |
| 未认证 | 去认证 | 提交认证 | 无 |
| 待审核 | 待审核 | 查看进度 | 通过、驳回 |
| 已认证 | 已认证 | 查看认证信息 | 查看记录 |
| 已驳回 | 审核未通过 | 查看原因、重新提交 | 查看记录 |

## 2.2 唯一性 / 并发性

- 同一用户同一时间仅允许存在一条“待审核”的医生认证申请。
- 用户在“待审核”状态不可重复提交；重复请求需提示“认证资料正在待审核，请勿重复提交”。
- 运营审核时需校验记录仍为“待审核”；已被其他运营人员处理的记录不可重复审核。
- 每次驳回后重新提交生成新的认证记录，不覆盖历史记录。

## 2.3 字段定义

| 字段名称 | 含义 | 是否必填 | 规则 |
| --- | --- | --- | --- |
| 真实姓名 | 医生本人姓名 | 是 | 2-20 个字符 |
| 联系手机号 | 当前账号手机号 | 是 | 默认带入并脱敏展示，可确认不可修改 |
| 执业医院 | 当前执业机构全称 | 是 | 2-50 个字符 |
| 所在科室 | 当前所在科室 | 是 | 从预设科室中选择 |
| 医生职称 | 当前职称 | 是 | 医师 / 主治医师 / 副主任医师 / 主任医师 |
| 医师资格证书编号 | 资格证书编号 | 是 | 6-30 位数字或字母 |
| 医师资格证书照片 | 资格证明 | 是 | 1 张，JPG/PNG，单张不超过 10MB |
| 医师执业证书照片 | 执业证明 | 是 | 1 张，JPG/PNG，单张不超过 10MB |
| 补充说明 | 用户补充信息 | 否 | 0-200 个字符 |
| 驳回原因 | 运营审核意见 | 驳回时必填 | 1-200 个字符，用户端可见 |

## 2.4 关键联动逻辑

- 审核通过：认证状态更新为“已认证” → 用户特征“是否医生”更新为“是” → 自动添加系统标签“医生” → 命中“是否医生=是”的自动标签和用户群。
- 审核驳回：认证状态更新为“已驳回” → “是否医生”保持“否” → 不添加医生标签 → 用户端展示驳回原因和“重新提交”。
- 驳回后重新提交：认证状态更新为“待审核”，保留上次记录；新提交记录进入审核队列。
- 已认证用户若历史上存在驳回记录，用户详情仍展示全部记录，但当前身份以最新有效审核结果为准。
- “是否医生”为系统只读特征，运营人员不可在用户资料、手动标签或导入流程中直接修改。

## 2.5 标签规则

- 系统内置自动标签“医生”，规则固定为“用户特征 / 是否医生 / 等于 / 是”。
- 系统标签不可删除，不允许修改名称和规则；可查看命中人数和用户明细。
- 新建自动标签时，“用户特征”指标组增加“身份认证”，枚举值为“待审核、已认证、已驳回、未认证”。
- 新建/编辑标签的条件区采用左右分栏配置：左侧以条件卡片展示“身份认证”和四种状态下拉框，右侧“用户特征”指标勾选“身份认证”后生成条件；删除条件时同步取消右侧勾选。
- 医生身份变化后，自动标签命中结果同步刷新。

## 2.6 用户群规则

- 新建/编辑用户群时，“用户特征”指标组增加“身份认证”，枚举值为“待审核、已认证、已驳回、未认证”。
- 新建/编辑用户群复用标签条件区样式：左侧条件卡片配置“身份认证=待审核/已认证/已驳回/未认证”，右侧指标选择勾选状态与条件实时联动。
- 支持与其他条件按“全部满足”或“任一满足”组合。
- 保存用户群时仅保存身份认证条件，不展示预计命中人数。

## 2.7 异常处理规则

- 图片上传失败：保留其他已填字段，提示失败原因并允许重试。
- 提交失败：不生成认证记录，表单内容保留。
- 审核记录已处理：阻止重复操作，刷新页面并展示最新状态。
- 认证资料缺失：运营端审核按钮禁用，并提示“资料不完整，无法审核”。
- 数据加载失败：页面展示重试入口，不将失败误展示为“未认证”。

## 2.8 权限规则

- 普通用户仅能查看和提交本人认证资料。
- 运营人员需具备“用户中心-医生认证审核”权限方可执行通过或驳回。
- 无审核权限的运营账号可查看认证资料和审核记录，但不展示审核操作按钮。
- 审核记录包含审核人、审核时间、审核结果、审核意见，不允许编辑或删除。

## 2.9 数据来源

- 用户基础信息来自现有用户中心。
- 医生认证资料来自用户在微信小程序的主动提交。
- 是否医生、医生标签、认证状态和审核记录由认证审核流程产生。

## 2.10 通知机制

- 提交成功后，小程序认证页展示“待审核”。
- 审核通过后，个人信息页昵称旁展示“医生”标识。
- 审核驳回后，认证入口展示“审核未通过”，认证详情展示驳回原因。

# 3. 页面说明

## 3.1 运营后台｜用户管理列表

- 页面路径：用户中心 / 用户管理。
- 搜索区补充会员ID、手机号、用户昵称、用户性别、当前阶段、注册时间、标签、客户人群、最后消费时间、积分余额、来源渠道、邀请渠道、企微ID等字段。
- 新增列表字段：用户手机号、性别、生日、当前阶段、来源渠道、邀请渠道、邀请人、注册时间、上次消费时间、三方编码、身份认证；不展示“是否医生”列表字段。
- 身份认证状态为“待审核、已认证、已驳回、未认证”；操作顺序统一为“给积分 → 打标签 → 审核”，仅待审核用户展示“审核”，已驳回用户不展示审核操作。
- 列表操作不展示“详情”，各操作按钮之间保持明确间距。
- 点击“审核”打开审核弹窗，可选择通过/驳回，填写审核意见，上传审核凭证并填写后台备注；通过时审核意见非必填，驳回时审核意见必填。
- 支持搜索、筛选、清空、分页、全选、批量添加标签、刷新和导出，均作用于页面内真实模拟数据。

## 3.2 运营后台｜用户详情

- 页面采用左右两列布局：左侧展示用户头像、昵称、手机号、用户ID、注册时间、来源、邀请码、邀请渠道、邀请人、优惠券、积分、会员消费、会员售后；右侧展示用户资料及业务明细。
- 右侧内容区依次展示：用户资料、宝宝信息、宝宝档案记录、标签群组、收货地址、企微资料、分销信息。
- 用户资料不展示“医生”标识和“是否医生”字段；保留“身份认证”字段，状态为待审核、已认证、已驳回、未认证。
- “身份认证”提供“详情”入口，点击后弹窗展示用户提交的认证信息及审核记录。
- 认证详情包含真实姓名、联系手机号、执业医院、所在科室、医生职称、资格证书编号、提交时间、补充说明；审核记录包含记录ID、提交时间、审核结果、审核人、审核时间、审核意见。
- 用户详情页顶部不展示“审核认证”操作按钮，审核统一从用户管理列表进入。

## 3.3 运营后台｜标签列表与标签配置

- 标签列表展示标签名称、说明、标签类型、命中会员数、规则、更新时间；不展示系统标识，操作为“新增”“删除”。
- 标签名称不再展示“系统”标识；标签类型统一展示“自动打标”或“手动打标”，列表展示更新时间。
- 操作列提供“新增”“删除”，按钮之间保持间距。
- 新建/编辑自动标签的“用户特征”指标组新增“身份认证”。
- 选择后可配置“等于 待审核/已认证/已驳回/未认证”；规则区域实时展示已选条件，不展示预计命中人数。

## 3.4 运营后台｜用户群列表与用户群配置

- 用户群列表新增示例用户群“医生内购人群”，人数根据认证结果实时变化。
- 人群名称不再展示“动态”标识；列表增加标签类型字段，统一展示“自动打标”或“手动打标”。
- 操作列提供“新增”“删除”，按钮之间保持间距。
- 新建/编辑用户群的“用户特征”指标组新增“身份认证”。
- 条件配置与保存结果需真实联动，不展示预计命中人数。

## 3.5 运营后台｜系统配置 / 业务配置

- 菜单路径：系统配置 / 业务配置。
- 在现有“宝宝信息配置”分区下新增“身份认证配置”分区。
- 身份认证：必填单选，支持“开启、关闭”；默认开启。开启时展示“填写跳转”配置，关闭时隐藏“填写跳转”配置。
- 填写跳转：仅在身份认证开启时展示，非必填；支持选择装修页、固定页面、品牌、后台分类、指定商品、我的小程序、其他小程序、H5链接、弹窗、视频号、优惠券礼包、商品分组、抽奖码抽奖。
- 填写跳转不展示右侧注释文案。
- 身份认证配置不展示“小程序展示/小程序预览”配置项。
- 字段名称、控件和备注在同一行展示，字段与备注文案均不换行；页面宽度不足时由内容区横向滚动承载。
- 默认选择“固定页面”，点击医生认证入口时进入医生认证页；其他选项按对应页面类型执行模拟跳转。
- 点击“保存”后配置生效并持久化；未保存的修改刷新后不生效。

## 3.6 微信小程序｜个人中心主页

- 个人中心主页本期移除，不提供独立页面入口。
- 已认证用户的“医生”身份标识在个人信息页展示。

## 3.7 微信小程序｜个人信息

- 页面视觉参考新版个人信息页：浅紫头部展示头像、昵称、邀请码、编辑入口与邀请海报入口；下方以白色大分区展示孕期/宝宝信息卡片和“添加宝宝/孕期”主按钮。
- 身份认证开启时，头部快捷入口展示“医生认证”和当前认证状态，点击后按业务配置中的“填写跳转”执行；关闭时不展示该入口。
- 已认证状态同时在昵称旁展示医生标识；认证资料保持只读。

## 3.8 微信小程序｜医生认证

- 个人中心页移除，不再提供独立个人中心入口。
- 填写页参考宝宝档案样式：浅灰页面背景、顶部微信小程序导航、灰色分组标题、白色圆角信息卡片和左右对齐字段行。
- 未认证/已驳回：展示认证表单；已驳回时顶部展示驳回原因，并回填上次资料。
- 待审核：展示审核状态提示，并保留与提交页一致的可编辑表单；用户可修改资料后重新提交审核。
- 已认证：展示“认证已通过”状态和全部提交信息，页面沿用提交页字段卡片样式，字段只读且不展示提交按钮。
- 表单字段标签、输入框、选择框、证书上传控件和补充说明在每行垂直居中对齐。

# 4. 状态与异常

## 4.1 页面默认态

- 用户管理默认展示全部用户，新增筛选均为“全部”。
- 标签和用户群配置默认“全部满足”。
- 小程序根据当前登录用户的认证状态进入对应页面状态。

## 4.2 空态

- 用户列表搜索无结果：展示“未找到符合条件的用户，请调整筛选条件”。
- 审核记录为空：展示“暂无审核记录”。
- 标签和用户群配置不展示预计命中人数。

## 4.3 权限态 / 不可操作态

- 待审核：用户端展示审核状态，表单可编辑，提交按钮文案为“重新提交审核”。
- 已认证：用户端认证资料只读，页面不展示提交按钮。
- 无审核权限：后台只读展示资料与记录。

## 4.4 状态流转

- 未认证 → 待审核：用户提交完整认证资料。
- 已驳回 → 待审核：用户修改资料并重新提交。
- 待审核 → 待审核：用户修改资料并重新提交，更新提交时间。
- 待审核 → 已认证：运营审核通过。
- 待审核 → 已驳回：运营填写原因并驳回。

---

# 5. 验收要点

- 用户提交后，后台同一用户立即变为“待审核”，详情能看到本次资料。
- 后台通过后，认证状态更新为“已认证”，认证详情可查看最新提交信息和审核记录。
- 后台驳回后，小程序展示驳回原因并允许重新提交；用户“是否医生”仍为“否”。
- 通过/驳回均生成审核记录，重复审核被阻止。
- 标签和用户群均可使用“身份认证=待审核/已认证/已驳回/未认证”作为条件。
- 业务配置关闭身份认证并保存后，个人信息页隐藏认证入口；重新开启并保存后恢复展示。
- 填写跳转选项与参考图一致，选择“固定页面”时能够进入医生认证页。
- 页面刷新后，原型中的认证状态、审核记录、标签人数和用户群人数仍保留。
